# Test Binance Traiding

Тестовое задание: работа с JSON, MySQL, DataTables и API Binance на PHP.

Исходные данные — JSON-файл [`courses.json`](courses.json).

## Основные задачи

1. Зарегистрировать бесплатный хостинг с поддержкой PHP и MySQL.
2. Создать MySQL базу данных и загрузить в неё JSON-файл (`courses.json`).
3. Вывести на страницу таблицу с данными, полученными из базы данных (пункт 2).
4. Применить к таблицам JS-библиотеку [DataTables](https://datatables.net/) с возможностью сортировать столбцы.

## Необязательные, но желательные пункты

1. Добавить на страницу форму добавления записи в существующую базу данных.
2. Добавить на страницу форму добавления записи в JSON-файл.
3. С биржи [Binance](https://www.binance.com/ru) по API получить курс валют и вывести на страницу в виде таблицы.
4. В данных из JSON-файла подсветить валютные пары по окончанию:
   - `BTC` — зелёным;
   - `ETH` — жёлтым;
   - `USDT` — синим.

## Настройка

Скопируйте `config.example.php` в `config.php` и укажите свои параметры подключения к MySQL:

```bash
cp config.example.php config.php
```

`config.php` исключён из git и не должен попадать в репозиторий.
